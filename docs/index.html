Step 1 · Tokenization

A token is not a word. Click any token below — the panel shows exactly what the model gets.

The model never sees letters — it sees token IDs

Look at „penicillin“

It arrives as two tokens, penic + illin. Rare medical words get assembled from pieces the tokenizer already knows.

Why this matters in medicine

German compounds are worse: Herzkatheteruntersuchung can split into a handful of fragments. A vocabulary built on general web text fits clinical German badly.

Step 2 · Embedding + position

A lookup, plus where the token stands.

et  =  E[xt]  +  pt

Move the token along the sentence

pt is not learned

It is computed, so the model can tell position 3 from position 30 even in a sentence longer than anything it saw in training:

p[2i]   = sin(t / 10000^(2i/d))
p[2i+1] = cos(t / 10000^(2i/d))

Here d = 4, so there are two sin/cos pairs.

But this vector is the same in every sentence — it has not read anything yet. That is what Step 3 is for.

What the slider does

      
pi = exp(zi/T) / Σj exp(zj/T)

      
Low T repeats the same safe word. High T invents. Same model,
      same prompt, different note every time — that is what makes synthesis possible, and
      what makes it need checking.

      
The catch. A generated note can be fluent, confident and the
      opposite of the truth — and the likelihood will not tell you which.
